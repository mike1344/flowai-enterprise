# 11 通用任务卡与交接模板

本模板适用于人工、团队及任何 AI 开发工具。任务以编号和仓库文件为事实依据，不依赖单一工具会话。

## 任务卡

| 项目 | 填写内容 |
|---|---|
| 任务 ID | 与 02 任务清单一致 |
| 需求追踪 | 对应 10 中需求/ADR |
| 优先级 | P0 / P1 |
| 负责人 | 执行者与验收人 |
| 前置依赖 | 必须完成的任务 ID |
| 输入 | API 契约、数据模型、现有代码、测试数据 |
| 范围 | 本任务必须完成的功能 |
| 非范围 | 本任务明确不做的内容 |
| 交付物 | 文件、接口、迁移、文档、测试报告 |
| 验收标准 | 可观察、可复现的通过条件 |
| 测试证据 | 命令、环境、结果、日志或报告路径 |
| 风险及回滚 | 兼容性、数据迁移、恢复方案 |
| 状态 | TODO / READY / DOING / BLOCKED / REVIEW / TESTED / DONE |

## 审核检查

- [ ] 需求与范围一致
- [ ] 安全与资源权限检查通过
- [ ] 数据约束、事务、幂等检查通过（适用时）
- [ ] 自动化测试有真实证据
- [ ] API/部署/变更文档同步更新
- [ ] 验收人确认 DONE
