# 01 项目总纲与架构

## 1. 产品目标与非目标
目标：实现可创建、配置、测试和发布多个 AI 应用的企业 AI 平台；可复用授权知识库，利用预置 Agent 工具调用独立工业业务系统，完成从设备咨询、历史故障检索到用户确认后创建维修工单的闭环；可单机容器化交付并诊断故障。

非目标：ERP/MES/CRM 全功能、工业硬件控制、拖拽编排、多租户计费、Kubernetes、高可用集群、默认完全离线部署、任意 SQL/URL/代码执行工具。

## 2. 逻辑与物理架构
```text
Browser (Vue3 single SPA)
  /admin/*   管理布局: 应用/知识库/工具/用户/监控
  /apps/:slug/* 独立应用布局: 会话/消息/引用/确认
       |
Reverse proxy (same origin /api/flowai -> flowai-api)
       |
FlowAI API (FastAPI): Auth/RBAC, App, Publish, KB, Chat, Agent, Tool Registry, Trace
  |--> MySQL: flowai_db (dedicated account)
  |--> Redis/Celery Worker: document ingestion, embeddings
  |--> ChromaDB: vector index (authorized namespace/metadata filtering)
  |--> External LLM/Embedding adapters (credentials via secrets)
  |--> Industrial Service API via private service network + verified identity context
            |--> MySQL: industrial_db (dedicated account)
```
Docker Compose 单机编排：frontend/reverse-proxy、flowai-api、flowai-worker、industrial-api、mysql、redis、chromadb。对外仅暴露前端入口；内部服务不公开端口。MySQL 两个逻辑数据库与独立账号；每个服务只持有自己的数据库凭证。Redis/向量库持久卷；生产环境使用 TLS 入口。

## 3. 建议技术栈（可通过变更记录调整）
- 前端：Vue3 + Vite + Vue Router + Pinia + Element Plus；同一 SPA，不同布局/路由守卫。
- 两个后端：Python + FastAPI + Pydantic v2 + SQLAlchemy 2 + Alembic + MySQL 8。
- AI：LangChain（模型/工具适配）+ LangGraph（可恢复状态编排）；ChromaDB；可插拔 LLM 与 Embedding 适配器。
- 异步：Celery + Redis（文档摄取）；监控：结构化日志 + Trace ID + 内置指标；测试：pytest/HTTPX、Playwright。
- 外部模型 API 首选；本地模型只定义适配接口，不承诺 P0 可离线运行。

## 4. 单仓库目录目标（规划，不是现有目录）
```text
flowai-enterprise/
  frontend/                  # 单 Vue3 SPA
  services/
    flowai-api/              # 平台 API、Agent、RAG、RBAC
    industrial-api/          # 工业业务 API 与独立迁移
  packages/contracts/        # 可选：OpenAPI 产物/纯契约，禁止跨库 ORM
  infra/compose/             # compose、代理配置、示例环境变量
  tests/e2e/                 # 跨服务端到端验收
  seed/                      # 合成工业客户/设备/故障/工单数据
  docs/                      # 当前文档及后续 ADR、运行手册
```

## 5. 数据与信任边界
- 浏览器 -> FlowAI：用户会话鉴权、CSRF（若 cookie 会话）、速率限制、应用访问授权。
- FlowAI -> Industrial：服务身份 + 经过验证的用户上下文/身份映射；工业服务独立校验业务范围；禁止信任客户端传入的 `user_id`、`confirmed`。
- 模型输出、知识文档、工具结果均视为不可信内容；模型不得决定最终授权、直接发 SQL 或控制工业设备。
- 客户、设备、工单归 Industrial 所有；应用、知识库、发布版本、会话、Trace 归 FlowAI 所有；通过 Trace ID 关联但不跨库写入。

## 6. 交付物
运行系统、OpenAPI、迁移、种子数据、自动化测试、RAG/Agent 评测结果、Docker 部署/备份/故障排查手册、需求与解决方案说明、PoC/验收报告。所有结果须标明实测环境与日期。
