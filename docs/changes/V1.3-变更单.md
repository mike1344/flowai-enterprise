## 4. 风险与边界

- **不改变已冻结需求范围**：四项均为非功能性/质量增强，不新增多租户、拖拽编排、K8s、工业硬件控制（那些属 V2 候选）。
- **成本**：T1/T3 会真实调用外部模型与 embedding，产生 API 费用；脚本默认限额（并发 ≤4、时长 ≤60s），可 `--dry-run` 只校验连通性。
- **回滚**：T2/T3 涉及迁移，必须先按 `infra/backup` 备份；集合隔离只增不改，可切回旧索引。
