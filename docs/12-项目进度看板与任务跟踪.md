## 如何查看进度（推荐）

1. 打开项目根目录 `progress/进度看板.html`，即可查看总进度、P0/P1、各模块完成比例、任务状态和阻塞情况。
2. 在任务行修改状态、负责人、日期、证据。浏览器内即时重算进度；**只有 DONE 且填写验收证据的任务才计入完成百分比**。
3. 点击“导出进度 JSON”，覆盖保存 `progress/任务进度.json`，并将它提交 Git。更换浏览器/电脑/AI工具时点击“导入 JSON”继续。浏览器本地数据不能替代 Git 中的进度文件。
4. `progress/任务总表.csv` 可用于筛选与分配；`progress/任务进度.json` 是唯一的跨工具权威进度记录，CSV 是初始导出参考，不自动双向同步。
5. 每完成一个任务，更新对应测试证据、文档和提交记录；进入下一任务前核验依赖。

## 权重与完成定义

- P0 占总进度 **80%**，P1 占 **20%**；每个任务按相对工作量分配权重，不按任务数量简单平均。
- 总体完成率 = Σ（已验收 DONE 任务的权重）；P0/P1 阶段完成率 = 阶段已验收权重 / 阶段总权重。
- `TODO → READY → DOING → REVIEW → TESTED → DONE`；`BLOCKED` 可从非 DONE 状态进入。TESTED 仅表示测试完成，未通过正式验收不计完成。
- DONE 前必须：依赖全部 DONE、测试通过、关键安全/事务检查通过、证据可追溯、验收记录齐全。
- 发现 DONE 的任务存在关键缺陷时应撤回状态，重新评估下游任务。
- 看板中的“预计权重”不是工时、不是已经完成的工作量。不得把 DOING 自动算成 50% 完成。
