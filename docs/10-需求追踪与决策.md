## 2. 已冻结架构决策
- ADR-001：单仓库、双 FastAPI 独立服务、单 Vue3 SPA 双布局。
- ADR-002：工业业务与 FlowAI 独立数据库、只通过 API 集成。
- ADR-003：单企业 Docker Compose 私有化；外部模型 API 优先。
- ADR-004：多应用、共享授权 KB、最新 READY 索引；P1 回滚。
- ADR-005：预置工具注册表；业务写操作需人工确认；疑似重复工单需二次确认。
- ADR-006：工单 fault_id 可空；独立 ServiceUser + 身份映射；工单操作审计与业务事务一致。
- ADR-007：内置日志与 Trace；P1 扩展统计、备份恢复与升级演练。

## 3. 实施前需以 ADR 明确但不影响产品范围的技术细节
1. 跨服务认证具体机制：推荐内部服务凭证 + 短时签名最终用户声明（或受信 JWT）；定义 issuer/audience/expiry、撤销与密钥轮换，拒绝裸传用户 ID。
2. 写操作授权 token 签发、一次性消费/重放防护、与重复确认 token 的绑定和时效；预检与正式创建的请求规范化规则。
3. 工单重开后的 resolved_at/closed_at 字段语义；建议保留最近一次时间并以 TicketAction 作为完整历史。
4. 管理写 API 的 P0 范围：客户/型号/设备/故障/服务人员是否只需受控初始化 + 查询，还是提供完整管理 CRUD；建议 P0 优先 seed+必要受控管理接口，避免建设第二套完整后台。
5. RAG 评测评分规范与阈值（在 Gate C 前冻结）；具体 Embedding 模型、Chunk 策略、向量集合隔离策略。
6. API 认证/会话方案、CSRF/CORS、部署 TLS 入口、上传文件限制和日志保留期。
7. 索引删除/文档删除时的延迟清理与共享引用保护；发布应用会话版本绑定策略。

上述为**实施细节待决项**，不是重新开放已冻结的产品范围。每项在其首个依赖任务开始前写入 ADR；如影响已冻结需求，走变更控制。
