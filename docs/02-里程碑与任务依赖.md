# 02 里程碑、任务分解与依赖

## 1. 规则
- P0 先完成；P1 不得阻塞 P0 验收。任务标记 `TODO/DOING/BLOCKED/TESTED/DONE`；只有满足 DoD 才能 DONE。
- **依赖不是工期估算**。同一模块可拆分，但不可越过必要接口契约与安全检查。
- 每项任务交付：实现、数据库迁移（若有）、单测/集成测、异常/越权用例、OpenAPI/文档、可复现验收证据。

## 4. 阶段关卡
- Gate A（基础）：M00 全部 DONE；两服务数据库隔离、迁移可重放。
- Gate B（业务）：M01 全部 DONE；工业服务可独立 API 测试、工单写入事务完整。
- Gate C（AI 核心）：M02-M04 全部 DONE；RAG/Agent/权限/确认闭环。
- Gate D（P0）：M05-M06 全部 DONE；单机部署及安全验收通过。
- Gate E（P1）：M07-M08 全部 DONE；回滚、恢复、交付材料齐备。
