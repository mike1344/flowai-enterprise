# 00 快速开始（本机 5 分钟跑起来）

> 适用：FlowAI Enterprise V1.2｜本机实测版本｜完整说明见 `01-部署与运维手册.md`
> 本机没有 PowerShell 7（`pwsh` 不存在），文档里的 `pwsh` 一律用 `powershell.exe` 代替。

## 1. 前置

```powershell
cd F:\Y1                      # 仓库根
docker version                # 需要 Docker Desktop 已启动
```

## 2. 启动

```powershell
cd F:\Y1\infra\compose
Copy-Item .env.example .env   # 仅首次；填数据库口令 / SERVICE_JWT_SECRET / SESSION_SECRET / CSRF_SECRET
docker compose up -d --build  # 重建镜像并启动，迁移自动执行
docker compose ps             # 期望 6 个 healthy + 2 个 *-migrate Exited(0)
```

日常只启动（代码未变，不重建）：

```powershell
cd F:\Y1\infra\compose; docker compose up -d
```

## 3. 初始化数据（幂等，可重复执行）

```powershell
cd F:\Y1\infra\compose
docker compose run --rm -v F:/Y1:/repo -w /repo flowai-migrate    python seed/flowai_seed.py
docker compose run --rm -v F:/Y1:/repo -w /repo industrial-migrate python seed/industrial_seed.py
```

顺序不能反：工业侧的 `admin` 身份映射依赖平台管理员账号已存在。

## 10. 常用运维

```powershell
cd F:\Y1\infra\compose
docker compose ps                     # 健康状态
docker compose logs -f flowai-api     # 结构化 JSON 日志
docker compose restart flowai-api     # 重启单个服务
docker compose run --rm flowai-migrate        # 升级后补迁移
docker compose down                   # 停止，保留数据卷
docker compose down -v                # 停止并清空数据（慎用）
```

## 11. 常见坑

| 现象 | 原因 / 处理 |
|---|---|
| 8080 打不开 | 本机 `FRONTEND_PORT=8090`，不是文档默认的 8080 |
| 接口 403「工业服务拒绝业务授权」 | 种子没跑或顺序反了，重跑第 3 节 |
| 播种时报连不上 127.0.0.1:3306 | MySQL 不对外发布端口，必须用第 3 节的容器内方式 |
| `docker compose` 连不上引擎 | Docker Desktop 未启动 |
| 8090 被占用 | 改 `infra/compose/.env` 的 `FRONTEND_PORT` 后重启 |
| 页面还是旧版本 | 入口 HTML 已设 no-store；强刷或看页脚构建时间戳 |
