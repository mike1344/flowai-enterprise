# M00-02 验收证据：两后端骨架、单前端骨架、配置与健康接口

> 日期：2026-11-01｜执行者：DSH 实施代理｜环境见 `docs/audit/01-M00-01-环境清单.md`
> 结论：**PASS**——三端可独立启动，健康接口可测，真实 API 连通（含代理与 Trace 透传）。

## 1. 交付物

| 端 | 路径 | 内容 |
|---|---|---|
| FlowAI API | `services/flowai-api/` | `app/main.py`（liveness `/health`、readiness `/health/ready`、envelope `/api/v1/health|meta|echo`）、`app/core/{config,logging,trace,redaction,errors,readiness}.py`、`.env.example`、`requirements*.txt` |
| Industrial API | `services/industrial-api/` | 同上结构，独立 `.venv`/独立配置前缀 `INDUSTRIAL_`，`enable_admin_write_api` 默认关闭（ADR-011） |
| 前端 | `frontend/` | Vue3 + Vite + Vue Router + Pinia + Element Plus；`/admin` 管理布局、`/apps/:slug` 应用布局；`api/client.js` 统一信封与 Trace；开发代理 `/api/flowai`→8001、`/api/industrial`→8002 |

约定落地：统一响应体 `code/message/data/trace_id`、错误体 `code/message/details/trace_id`、`X-Trace-ID` 透传、CORS 白名单、JSON 结构化访问日志（不含请求头/体）、就绪检查不假报健康。
