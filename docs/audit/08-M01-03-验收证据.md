## 2. 状态机与规则（docs/03 §3 + ADR-010）

```
PENDING → IN_PROGRESS → RESOLVED → CLOSED
                ↑            ↓         ↓
                └── REOPENED ←─────────┘
```

- 新建必为 `PENDING`；进入 `IN_PROGRESS` 前必须分配 **ACTIVE** ServiceUser（`ASSIGNEE_INACTIVE`）。
- `RESOLVED` 必须填 `resolution` 并写 `resolved_at`（`RESOLUTION_REQUIRED`）。
- `CLOSED` 写 `closed_at`；重开必须填原因（`REOPEN_REASON_REQUIRED`），并按 ADR-010 将 `closed_at` 置空（历史由 `ticket_action` 保留）。
- 其他转移一律 409 `TICKET_INVALID_TRANSITION`。
- 所有变更携带 `If-Match` 版本号：缺失或过期 → 409 `RESOURCE_VERSION_CONFLICT`。
- 状态变更 + 版本自增 + 时间戳 + `STATUS_CHANGE` 记录在**同一事务**提交。
