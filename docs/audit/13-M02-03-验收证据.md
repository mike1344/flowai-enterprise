## 2. 生命周期与规则（docs/05 §1）

- `DRAFT → TESTING → PUBLISHED → DISABLED`；草稿测试成功后进入 `TESTING`。
- **发布校验**：模型必填且 ACTIVE、系统提示词非空、温度 0–2、max_tokens 1–32000；失败返回 422 `PUBLISH_VALIDATION_FAILED` + `problems` 列表。
- **快照不可变**：发布时把 `draft_config` 深拷贝进 `application_version.config`，并生成递增 `version_no`；旧版本置 `SUPERSEDED` 但内容不改。
- 修改已发布应用的草稿**不影响**线上快照；再次发布产生 v2。
- 停用后 `GET /apps/{slug}` → 404；未发布应用同样 404（不泄露存在性）。
