## 6. 指标口径说明

- 请求量/错误率/P95 均来自 `request_metric` 表（与访问日志同源，逐请求落库）
- `error_rate` = 5xx 数 / 窗口内请求数
- Token 用量：P0 使用 MOCK 模型，固定上报 0 并注明原因（不虚报）
