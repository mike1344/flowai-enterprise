## 2. 凭证保护规则

- 数据库只存**环境变量名**（`api_key_ref`），永远不存密钥值（docs/03 §6「ModelConfig 仅密钥引用」）。
- `api_key_ref` 必须是 `^[A-Z][A-Z0-9_]{2,79}$`；提交疑似密钥串（`sk-...`）直接 400。
- 响应返回 `api_key_configured` 布尔值，**不回传**密钥本身。
- 连通性测试：`KEY_NOT_CONFIGURED` / `UNREACHABLE` / `TIMEOUT` / `HTTP_ERROR` / `DISABLED` 均为结构化结果，HTTP 200 + `ok=false`，绝不 500、不回显密钥。
