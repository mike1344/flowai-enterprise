## 2. 安全与一致性（docs/04 §6、docs/05 §5、ADR-009）

- 服务令牌 60 秒有效，`sub` 为最终用户，工业侧**再次鉴权**（测试断言令牌 claims 与 idempotency-key）。
- 写操作三要素：服务端确认令牌（一次性、绑定执行/用户/参数摘要、300s）+ 重复风险二次确认令牌 + 稳定幂等键。
- 用户拒绝 → `CANCELLED`，**不发起任何写入调用**。
- 超时 → `TIMED_OUT` + 「结果待核实」，**绝不返回工单号**；幂等键保留以便安全重试。
