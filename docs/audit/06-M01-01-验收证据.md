## 2. 数据库约束（由 DB 强制，非仅应用层）

| 约束 | 实现 |
|---|---|
| `customer.customer_code` / `device.device_code` / `device.serial_number` / `product_model.model_code` / `fault_record.fault_no` 唯一 | UNIQUE 约束 |
| 客户→设备、型号→设备、设备→故障 外键 `ON DELETE RESTRICT` | FOREIGN KEY |
| `customer.status ∈ {ACTIVE,INACTIVE}`、`service_level ∈ {STANDARD,PRIORITY}` | CHECK |
| `product_model.status ∈ {ACTIVE,DISCONTINUED}`、`warranty_months 0..120` | CHECK |
| `device.status ∈ {ACTIVE,MAINTENANCE,RETIRED}` | CHECK |
| 保修日期同空或同非空且 `end >= start` | CHECK |
| `fault_record.severity ∈ {LOW,MEDIUM,HIGH,CRITICAL}`、`source ∈ {MANUAL,AGENT,SYSTEM}` | CHECK |
| 索引 | `ix_device_customer_status`、`ix_fault_record_device_occurred` |
