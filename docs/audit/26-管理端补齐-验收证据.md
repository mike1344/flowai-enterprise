# 管理端补齐验收证据（消除「待开发」占位）

> 日期：2026-11-01｜背景：用户反馈「怎么还有那么多没有实现」。定位结果：**后端接口齐全，但前端缺少 3 个管理页面，且系统状态页仍写着「待开发」**（M00-02 骨架阶段遗留文案）。

## 1. 问题定位（真实缺口）

| 现象 | 根因 |
|---|---|
| 「平台模块」页所有模块标 `待开发` | `SystemsView.vue` 是 M00-02 骨架时写的静态表，之后从未更新 |
| 侧边栏只有 总览/应用/知识库/统计/模块 | 工具、用户、监控三个页面**未创建**（后端接口早已实现） |
| 应用端顶部写「工单闭环将在 M05-02 开放」 | 骨架阶段文案未更新 |
| 应用版本回滚、索引版本回滚只在 API 层 | 前端无入口 |

## 2. 本次补齐内容

| 项 | 内容 |
|---|---|
| **新增「模型配置」页** `/admin/models` | 模型列表（协议/BaseURL/模型名/密钥是否配置）、新建配置、**连通性测试**（真实调用 provider） |\n| **新增「工具中心」页** `/admin/tools` | 预置工具列表（code/类型/参数 Schema 必填项）+ 按应用开关授权（绑定/解绑） |
| **新增「用户与角色」页** `/admin/users` | 用户列表（角色、权限数、状态）、新建用户、分配角色、查看/新增资源授权 |
| **新增「监控与审计」页** `/admin/monitoring` | 请求量/错误率/P95/Token 四卡、按 Trace ID 查询（审计+工具调用+执行+请求）、最近 50 条审计 |
| **应用页新增「版本」对话框** | 版本历史（含状态、发布时间、提示词摘要）+ **回滚到此版本** |
| **知识库页新增「索引版本」对话框** | 版本列表（状态/分块/是否 active）+ **切回历史 READY 索引** |
| **系统状态页重写** | 8 个模块全部标「已实现」，并给出真实入口路径 |\n| **应用端新增「执行步骤」面板** | 每条助手消息显示模型名与 Token，点开查看结构化工具步骤（工具/状态/耗时/Trace），不含内部推理 |
| **侧边栏与文案修正** | 新增 3 个菜单项；「逐步开放」改为「均已实现」；应用端文案改为「会话、引用与工单确认已启用」 |
| **后端补一个接口** | `GET /api/v1/auth/users`（用户列表，需 `platform:user:manage`） |
