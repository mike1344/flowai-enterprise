## 4. 编码与运行约定（本轮确立）

1. **`.ps1` 脚本**：UTF-8 **带 BOM**。实测：无 BOM 的中文脚本在 PS 5.1 下解析失败（`字符串缺少终止符`）。
2. **文档/配置/源码**：UTF-8 无 BOM；换行 LF（`docs/` 现有文件为 LF）。
3. **脚本执行策略**：本机 `LocalMachine=Unrestricted`，但会话策略未定义，实测直接运行仍被 `AuthorizationManager` 拒绝；统一以
   `Set-ExecutionPolicy -Scope Process Bypass -Force` 后再调用，或 `pwsh -NoProfile -ExecutionPolicy Bypass -File <脚本>`。
4. **命令前缀**：本文所有命令在 `F:\Y1` 下执行；中文输出前先 `[Console]::OutputEncoding=[System.Text.Encoding]::UTF8`。
5. **沙箱**：工作区为 `workspace-write`；写工作区外路径需审批；WMI/CIM 被拒属预期限制。

## 5. 依赖版本建议（供 M00-02 落地，非冻结架构）

> `docs/01 §3` 已定技术栈（FastAPI/Pydantic v2/SQLAlchemy 2/Alembic/MySQL 8、Vue3+Vite+Element Plus、Celery/Redis/ChromaDB）。以下仅为**版本与驱动选择**建议，M00-02 写入 `requirements.txt` / `package.json` 后由测试验证。

| 层 | 建议 | 理由 |
|---|---|---|
| Python | 3.14.6 + 独立 `.venv` | 本机唯一可用解释器；隔离服务依赖 |
| MySQL 驱动 | **PyMySQL**（`mysql+pymysql://`） | 纯 Python，规避 cp314 编译轮子缺失（R-01） |
| Web | `fastapi` + `uvicorn[standard]` + `pydantic>=2` + `pydantic-settings` | 与 `docs/01 §3` 一致 |
| ORM/迁移 | `sqlalchemy>=2` + `alembic` | 两服务各自迁移目录 |
| 测试 | `pytest` + `httpx` | `docs/07 §1` |
| 异步 | `celery` + `redis` | 文档摄取任务（M03-02） |
| 前端 | `vue@3` + `vite` + `vue-router` + `pinia` + `element-plus`，包管理用 **npm** | pnpm 缺失（R-03）；版本在 M00-02 锁定 |
| E2E | `@playwright/test` | `docs/07 §1`，M05 起使用 |

**未验证**：以上组合在 Python 3.14 / Node 24 下的实际安装与启动结果——M00-02 必须实测并记录命令与输出，不得直接照抄本表宣称可用。
