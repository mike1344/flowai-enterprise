## 2. 权限链路

```
可检索知识库 = 用户 ResourceGrant（READ/USE/MANAGE）
             ∩ 应用 application_knowledge_base 绑定
             ∩ 文档未删除且 status=READY
```

- 绑定重复调用幂等；解绑不存在 → 404。
- 无授权 → `refused=true, reason=NO_RESOURCE_GRANT`；应用未绑 KB → `APP_HAS_NO_KB`。
- 多应用共享同一 KB：同一 KB 绑定两个应用均成功，解绑其一不影响另一。
