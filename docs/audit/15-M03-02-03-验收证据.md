## 2. 摄取与索引语义（docs/05 §2）

- 类型白名单：`application/pdf`、DOCX、`text/plain`、`text/markdown`；其他 → 400 `UNSUPPORTED_FILE_TYPE`；>20MB → 400 `FILE_TOO_LARGE`。
- 状态机：`PENDING → PROCESSING → READY | FAILED`；失败原因写 `error_message`（可诊断）。
- 每次摄取创建新的 `index_version`：成功 → `READY` 并设为 active，旧版本 `DEPRECATED`；**失败 → `FAILED`，旧 active 索引保持不变**（ACC-02）。
- 引用字段：`document_id`、`document_title`、`chunk_id`、`page_label`（无法定位时显式「页码不可用」），杜绝编造引用。

## 3. 检索与拒答（docs/05 §2）

- 检索范围严格等于权限交集；`NO_EVIDENCE` 时返回明确拒答文案，不输出未经验证内容。
- 相似度阈值 `REFUSAL_THRESHOLD = 0.18`；向量为确定性哈希嵌入（离线、无外部依赖），可替换为外部 Embedding。
