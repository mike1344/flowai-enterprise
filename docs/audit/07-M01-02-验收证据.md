| 类别 | 路径 | 说明 |

## 2. 授权规则（实测）

| 场景 | 期望 | 实测 |
|---|---|---|
| 客户用户读自己的客户 | 200，联系方式脱敏 | `138****5678` / `c***@example.com` ✔ |
| 客户用户读他人客户 | 404（不泄露存在性） | 404 ✔ |
| 客户用户读他人设备 / 故障列表 | 404 | 404 / 404 ✔ |
| 服务人员读任意客户 | 200 | 200 ✔ |
| 未映射 subject | 403 `PERMISSION_DENIED` | ✔ |
| 缺少令牌 | 401 `UNAUTHENTICATED` | ✔ |
| **映射 REVOKED 后同一令牌** | **立即 403「身份映射已撤销」** | ✔（IND-22） |
| 服务人员停用后 | 403「服务人员不可用」 | ✔（IND-23） |
| 故障列表分页与 `severity` 过滤 | `items,total,page,page_size` | total=3、page_size=2、HIGH 过滤=1 ✔ |
