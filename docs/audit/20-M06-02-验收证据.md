## 4. 遇到的问题与处理

| 问题 | 处理 |
|---|---|
| 构建时 PyPI 间歇性失败（`from versions: none`） | Dockerfile 增加 `PIP_INDEX_URL` 构建参数 + `--retries 10 --timeout 120`；本次使用镜像站构建成功 |
| `cffi` 在 Python 3.14 无 cp314 linux wheel | 运行镜像统一使用 `python:3.13-slim`（本机测试仍为 3.14） |
| flowai-api 缺 `httpx` 运行依赖 | 已加入 `requirements.txt` |
| 前端镜像未包含新页面（旧 dist） | 重建 frontend 镜像，`NPM_REGISTRY` 参数化 |
| Secure Cookie 导致 HTTP 登录失败 | `Secure` 改为按 `PUBLIC_BASE_URL` 是否 https 判定 |
